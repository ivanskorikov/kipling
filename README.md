# Rudyard Kipling — Poems

[Available via GitHub Pages](https://ivanskorikov.github.io/kipling/)

An attempt to preserve Rudyard Kipling’s poetic legacy and gather as many translations as possible, with a bilingual reading view (English alongside Russian).

Kipling’s poetry is in the public domain. I claim no copyright in the original texts or in any of the translations collected here. The site arrangement itself is dedicated to the public domain under [CC0 1.0](LICENSE).
